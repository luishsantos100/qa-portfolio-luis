# QA Portfolio - Luis Henrique dos Santos

## About Me

I am a Software Quality Assurance Analyst with 18+ years of professional experience across Software QA, IT Support, administrative operations, customer service, documentation, process control, and data accuracy.

Over the last several years, I have worked in Quality Assurance with manual testing, functional testing, regression testing, exploratory testing, acceptance testing, black-box testing, API/backend validation, SQL data validation, defect tracking, test documentation, Agile/Scrum collaboration, and automation support.

My QA background includes practical experience with tools and practices such as Postman, Insomnia, Cypress, GitHub Actions, SQL validation, Jira, Bitrix, ClickUp, test case design, bug reporting, and cross-functional collaboration with developers, Product Owners, and Scrum teams.

Before focusing on Software QA, I also worked in IT Support and Service Desk, supporting users, ticketing systems, network troubleshooting, ERP systems, Active Directory, Hyper-V environments, printers, email systems, cPanel, and Microsoft Exchange.

In addition, my earlier administrative and operational experience helped me develop a strong foundation in documentation, records management, data verification, ERP usage, customer service, process control, inventory support, financial routines, and attention to detail.

This portfolio was created to organize and showcase practical QA projects using modern and updated QA stacks, including API testing, test automation, CI/CD, BDD, performance testing, and AI-assisted QA practices.
